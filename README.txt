# Currency Converter

**Автор:** [Матвей Литвинов]

## Описание
GUI-приложение для конвертации валют с использованием бесплатного API exchangerate.host. Позволяет сохранять историю операций в JSON-файл.

## Функции
- Выбор валюты «из» и «в».
- Ввод суммы (проверка на положительное число).
- Получение актуального курса через интернет.
- Отображение результата.
- История всех конвертаций с датой.
- Сохранение/загрузка истории в файл `conversion_history.json`.
- Удаление записей или очистка всей истории.
