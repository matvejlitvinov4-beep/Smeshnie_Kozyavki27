# Random Password Generator

**Автор:** [Матвей Литвинов]

## Описание
Приложение с графическим интерфейсом (tkinter) для генерации случайных паролей с настраиваемыми параметрами. История паролей сохраняется в JSON-файл.

## Функции
- Настройка длины пароля (от 4 до 32 символов) с помощью ползунка.
- Выбор типов символов:
  - цифры (0–9),
  - буквы (a–z, A–Z),
  - специальные символы (!@#$%^&* и др.).
- Генерация пароля по кнопке.
- Копирование пароля в буфер обмена.
- История всех сгенерированных паролей (таблица с указанием длины и набора символов).
- Сохранение истории между запусками (файл `password_history.json`).
- Удаление отдельных записей или очистка всей истории.

## Установка и запуск
1. Убедись, что установлен Python версии 3.6 или выше.
2. Скачай файл `password_generator.py`.
3. Открой терминал/командную строку в папке с файлом.
4. Выполни команду:
   ```bash
   python password_generator.py
